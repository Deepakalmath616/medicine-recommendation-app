⚙️ Setup Instructions

⚠️ Important: Make sure you have Node.js and MongoDB installed before proceeding.

Step 1: Install Dependencies

Navigate to the backend folder and install required packages:

cd backend && npm install

Step 2: Configure Environment

Copy backend/.env.example to backend/.env and update with your credentials:

  • MongoDB connection string
  • JWT secret key
  • Gmail credentials for email notifications
  • Twilio credentials for SMS (optional)

Step 3: Start MongoDB

Make sure MongoDB is running on your system:

mongod

Step 4: Start the Application

Run the server:

cd backend && npm start

Or use the provided batch file: start.bat

Step 5: Access the Application

Open your browser and go to:

http://localhost:3000
